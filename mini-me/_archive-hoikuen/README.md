# 保育園ルート（凍結・2026-07-31）

保育園団体プランは **いったんサービスから除外** した。ここにあるのは除外時点の成果物一式。復活させる場合の再開点として残している。

## 凍結の理由

園へのインセンティブとして想定していた集合ジオラマ無償提供（推定 ¥30,000/園）を原価に計上すると、1園25人の前提で保育園プランの粗利が **¥1,213/体（23.0%）→ ¥13/体（0.3%）** まで落ちる。実質ゼロ粗利で人手工数だけを消費する構造だった。

加えて単価 ¥5,800/人 は卒園記念品の相場（500〜3,000円）の2〜10倍で、園の会費一括購入では通らない見込み。

## 復活させる場合に先に決めること

1. ジオラマを **有償化**（¥30,000 を園または保護者会に請求）するか、簡素化して原価 ¥10,000 程度に抑えるか、**1園あたり最低40人**を条件にするか
2. 「卒園記念品（園が買う）」ではなく「わが子の記念品（保護者が各自買う）」へフレーミングを変えるか
3. 園児の顔写真を扱う運用（保護者同意の取得・記録・撤回）の実務負荷を誰が持つか
