## 2. なぜ「園が写真を集めない」方式を推奨するのか

### 推奨する運用：保護者が各自アップロードする方式

```
園 ──[案内プリントを配布]──> 保護者
                                 │
                     各家庭のスマホから
                     専用URLにアクセスし、
                     わが子の写真をアップロード
                                 │
                     3Dプレビューで確認 → 各自で決済
                                 │
                                 ▼
                    株式会社企画7課で製造
                                 │
              ┌──────────────────┴──────────────────┐
              ▼                                     ▼
    園へ一括納品（卒園式で配布）        各家庭へ個別配送
       ※どちらか選択できます
```

### 理由：園が写真を預かると、園に個人情報のリスクが移るからです

園が園児の写真を集めて業者に渡す方式には、次の負担が発生します。

- 保護者全員から**写真の第三者提供に関する同意**を個別に取得する必要がある
- 集めた写真データの保管・受け渡し・削除の管理責任が園に発生する
- USBメモリ・メール添付などの受け渡し過程での**漏えいリスクを園が負う**
- 「うちの子の写真をどこに渡したのか」という問い合わせ対応が園に来る

**保護者が各自アップロードする方式なら、これらがすべて発生しません。**
写真は保護者から当社へ直接送信されます。園は「案内プリントを配る」だけです。

> 園が写真を取りまとめる方式をご希望の場合も対応可能ですが、
> その場合は保護者からの同意取得と園内での管理体制のご準備をお願いしています。
> 当社としては**保護者直接アップロード方式を強く推奨**します。

## 4. スケジュール例（卒園式の2ヶ月前を起点とした逆算）

**卒園式当日を「D」として、逆算した最短スケジュールです。**

| 時期 | やること | 担当 |
|---|---|---|
| **D-60日（約2ヶ月前）** | 実施決定・申込書のご提出。参加見込み人数の連絡 | 園 |
| **D-58日** | 園専用URL・園コードの発行。案内プリントの文面確定 | 当社 |
| **D-56日（8週前）** | **保護者へ案内プリントを配布** | 園 |
| **D-42日（6週前）** | **写真アップロード締切**（保護者に約2週間） | 保護者 |
| **D-40日** | 3Dプレビュー確認・承認／各自決済の締切 → **参加人数確定** | 保護者 |
| **D-40日 〜 D-8日** | 造形・仕上げ・検品（20〜25営業日／推定） | 当社 |
| **D-7日** | **園へ一括納品**。園で数量・氏名の確認 | 当社→園 |
| **D-3日** | 予備日（不足・不良分の再制作到着） | 当社 |
| **D 卒園式当日** | **園児へお渡し** | 園 |

> **推奨は3ヶ月前起点です。** 2ヶ月前起点は最短ラインで、
> 写真アップロードの遅れや年末年始・大型連休が挟まると余裕がなくなります。
> 3ヶ月前に着手いただければ、写真の再提出やプレビューのやり直しにも対応できます。

### アップロードが遅れるご家庭への対応

- 締切の1週間前・3日前に、当社から**保護者へ直接リマインドメール**を送ります（園からの督促は不要です）
- 締切に間に合わなかったご家庭は「不参加」として処理し、当日の配布物にも含めません
- **園から個別に催促していただく必要はありません。** 園の負担を増やさないための設計です

### 5-1. 誰が、何を、どこまで取得するか

**園から当社へ提供いただく個人情報は、原則としてありません。**
（園一括納品の場合のみ、納品時の照合用に園児氏名の一覧を当社から園へお渡しします）

### 5-2. 利用目的の限定

取得した写真・氏名は、**3Dモデルの生成と製品の製造・発送・お問い合わせ対応にのみ**使用します。
以下は行いません。

- 第三者への提供・販売（法令に基づく開示請求を除く）
- 当社の広告・SNS投稿への無断使用（**掲載する場合は必ず個別に許諾を取得します**。園や保護者から許諾がなければ一切使いません）
- AIモデルの学習データとしての二次利用

### 5-3. 保管と削除

| データ | 保管期間 |
|---|---|
| アップロードされた写真 | 発送完了後 **90日**で削除（推定・再制作対応のため） |
| 生成された3Dモデルデータ | 発送完了後 **90日**で削除（推定） |
| 注文情報（氏名・住所） | 法令上必要な期間（取引記録として）保管後、削除 |

保護者からのご希望があれば、**上記期間より前でも削除に応じます**（お問い合わせ窓口へ連絡）。

### 5-4. 技術的・組織的安全管理措置

- 通信はすべて**TLSで暗号化**（HTTPS）
- 保管は**アクセス制限をかけたクラウドストレージ**（Google Cloud／Firebase／東京リージョン）
- 決済は **Stripe** に委託。**当社はカード番号を保持しません**
- アクセス可能な担当者を限定し、アクセス記録を保持

- 事業者の登記事項証明書 ※要請時
