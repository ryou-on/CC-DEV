## 1. エグゼクティブサマリ

写真1枚をアップロードするとAIが3Dモデルを生成し、ミニチュアフィギュアを3Dプリントして自宅に届けるD2Cサービス。

**結論から言うと、この事業の成否は市場でも価格でもなく「AI生成メッシュを印刷可能な形に直す人手工数」を何分に収められるかで決まる。** 本計画の標準前提（1体あたり修正55分）では、オペレーター1名あたり月131体が生産上限となる。標準シナリオ（月150体・S40/M40/L20・店舗経由30%）の損益分岐点は、**オプション込み（台座40%・防水25%）の加重粗利 ¥4,446/体で 月367体（3名体制・稼働率93.4%）**。**オプション付帯をゼロと置くと加重粗利は ¥4,202/体に下がり、BEP は 月388体（3名体制・稼働率98.8%）**まで悪化する。つまり**BEP到達には3名がほぼ100%稼働する必要があり、繁忙期・有給・不良対応の余地が無い**。修正工数を25分まで圧縮できて初めて、月288体・営業利益 月65万円規模の黒字構造に乗る（詳細は §7 および `pl-simulation.html`）。

### 率直な所感（同僚として）
- **「必要初期投資 約250万円」だけを見て判断してはいけない。** 250万円は初年度の営業赤字（保守的前提で約1,087万円）の1/4も賄えない。**本事業の資金要件の本体は初期投資ではなく運転資金である。**
- **保守的シナリオ（月60体・工数75分・1名）では、損益分岐点が数学的に存在しない。** オペレーター1名が捌けるのは月96体、そこから生む粗利は約¥19.9万円で人件費¥35万円を下回る（1名あたり限界貢献 ▲約15万円）。**この前提のままでは、増員しても受注を増やしても赤字が拡大するだけ。** 工数75分は Phase 0 で必ず潰すべき数字。
- **アクアリウム軸のほうが筋がいい。** 単価が高く、防水という機能差別化が効き、SNS映えで自然流入が期待できる。リソースを割くならこちら。
- **Sサイズ（¥7,800）× 実店舗経由（バック15%）の組み合わせは粗利率12.7%（粗利 ¥994）で、事実上利益が出ない。** 店舗バックはM/L限定にするか、Sの店舗経由価格を別建てにすべき。

### 2-1. アクアリウム/テラリウム軸

| 顧客の課題 | 現状の代替手段 | ちいさなじぶん の提供価値 |
|---|---|---|
| 水槽レイアウトに「物語」を足したいが、既製のミニチュア人形は他人の顔で自己投影できない | 鉄道模型用フィギュア（Nゲージ人形）、海外製の情景人形 | 自分・家族・ペットの顔でレイアウトが作れる |

## 5. 差別化戦略

### 5-1. 防水コーティング（水中設置対応）
- **提供価値**: 水槽内に常設できるフィギュア。市販の鉄道模型用人形は水中で塗装が剥離するため、この用途は事実上空白。
- **技術要件（要検証）**: フルカラーレジン出力に対し、水槽用として安全な樹脂コーティング（アクアリウム用シリコン系／エポキシ系）を2〜3層。**魚毒性がないことの検証が必須**。ここを外すと生体死亡クレームに直結し、事業が即死する。
- **検証計画**: PoCフェーズで、①24週間の水中浸漬試験（変色・剥離・寸法変化）②生体（メダカ・ヤマトヌマエビ）を入れた小型水槽での90日安全性確認 を実施。**この検証が終わるまで「水中設置可」と広告してはいけない。**
- **価格**: +¥1,500（税込・税抜¥1,364）。原価 ¥805（材料¥180 + 工数15分・20体バッチ前提／推定）、限界貢献 ¥559（41.0%）。

### 5-2. アクアリウム専門店との提携網
- **設計**: 店頭にサンプル実物1体 + QRチラシ。QR経由の注文に対し**税抜売上の15%**をバック。
- **なぜ効くか**: このカテゴリは「実物を見ないと想像できない」。Web広告のCVRは低く、CPAが高止まりする。店頭のサンプル1体は、広告費換算で極めて効率がいい（推定）。
- **経済性の警告**: §7の通り、**S（¥7,800）+ 店舗バック15% は粗利 ¥994・粗利率12.7% で成立しない。** 対策 →（a）店舗経由はM/L推奨のPOPにする（b）Sの店舗バックを8%に下げる（c）S単品は店舗導線から外し、S+台座+防水のセット（税込¥10,500）でのみ提供する。**（c）を推奨。**
- **目標**: 1年目 提携20店舗、2年目 60店舗（推定）。

| 投資（推定） | 約80万円（Meshy Pro、出力費50件分、コーティング材、水槽試験） |
| **Go/No-Go 基準** | ① 修正工数の中央値 **45分以下** ② 印刷失敗率 15%以下 ③ 水中90日で剥離・変色なし ④ 生体安全性に問題なし。**①を満たせない場合はサービス設計を見直す（生成AIモデルの変更、ポーズテンプレート方式への転換）** |

### Phase 1: 小規模検証（4〜9ヶ月）
| 項目 | 内容 |
|---|---|
| 目的 | 有料顧客での単位経済性の確定 |
| 規模 | 月20〜60体。提携店舗5店 |
| KPI | ・修正工数中央値 ≤ 40分<br>・不良再制作率 ≤ 12%<br>・粗利率 ≥ 35%<br>・NPS ≥ +20<br>・返品率 ≤ 5%<br>・オプション付帯率（台座 ≥ 40% / 防水 ≥ 25%） |
| 撤退基準 | 6ヶ月時点で修正工数中央値が50分を切らない、または粗利率が25%を下回る場合は撤退または大幅ピボット |

### Phase 2: 拡大（10〜24ヶ月）
| 項目 | 内容 |
|---|---|
| 目的 | オペレーターを増やしつつ、工数を下げて営業黒字化 |
| 規模 | 月150〜320体。提携店舗20〜60店 |
| KPI | ・**修正工数中央値 ≤ 25分（最重要）**<br>・営業利益率 ≥ 10%<br>・リピート率 ≥ 15%<br>・店舗経由比率 25〜35%<br>・CAC ≤ ¥4,000 / LTV ≥ ¥18,000 |

### KPI ダッシュボード（毎週見る指標）
1. **1体あたり修正工数の中央値**（最重要。これ以外は後回しでいい）
2. 印刷失敗＋再制作率
3. 受注→出荷のリードタイム
4. オプション付帯率
5. 店舗別の注文数（バック支払いの妥当性検証）
6. 広告CPA / 店舗経由CPA の比較

## 7. 単位経済性のサマリ（詳細は cost-model.md）

### 7-1. プラン別粗利（オプションなし・直販ベース／推定・修正工数55分前提）

| プラン | 税込価格 | 税抜売上（送料含む） | 原価 | 粗利 | 粗利率 |
|---|---:|---:|---:|---:|---:|
| S 40mm | ¥7,800 | ¥7,818 | ¥5,761 | ¥2,057 | **26.3%** |
| M 65mm | ¥12,800 | ¥12,364 | ¥6,942 | ¥5,422 | **43.9%** |
| L 100mm | ¥19,800 | ¥18,000 | ¥9,453 | ¥8,547 | **47.5%** |


### 7-2. 店舗経由（バック15%）の場合

| プラン | 粗利 | 粗利率 | 判定 |
|---|---:|---:|---|
| S 40mm | ¥994 | **12.7%** | ✕ 成立しない |
| M 65mm | ¥3,676 | 29.7% | △ |
| L 100mm | ¥5,847 | 32.5% | ○ |

### 7-3. キャパシティが律速になるという構造

```
オペレーター1名の月間実働   = 160時間 × 稼働率75% = 120時間 = 7,200分
修正工数 55分/体 の場合     → 7,200 ÷ 55 = 131体/月 が生産上限
標準ミックス（S40/M40/L20、店舗経由30%、オプションなし）の加重粗利 = ¥4,202/体
1名あたり月間粗利           = 131 × 4,202 = ¥550,462
1名あたり人件費             = ¥350,000（社保込・推定）
1名あたり固定費貢献         = ¥200,462

その他固定費（CS 150,000 + 広告 300,000 + システム 30,000 + 事務所 100,000）= ¥580,000
→ 必要人員 = 580,000 ÷ 200,462 = 2.89人 → 3名
→ 3名時の生産上限 = 393体/月、粗利 = ¥1,651,386、固定費 = ¥1,630,000
→ 営業利益 = ¥21,386
→ 税抜売上 = 393 × ¥11,672.73 = 約¥4,587,000 に対し、営業利益率 わずか0.5%
```

> **営業利益率の分母は売上高であって売上総利益ではない。** 21,386 ÷ 1,651,386 = 1.3% は「営業利益 ÷ 売上総利益」であり、営業利益率ではない。正しくは 21,386 ÷ 4,587,000 = **0.47%**。

**つまり、修正工数55分のままでは、3名がフル稼働してようやくトントンにしかならない。** これは事業として成立していない。オプション付帯（台座40%・防水25%）を織り込んでも加重粗利は¥4,446/体にしか上がらず、構造は変わらない（BEP 月367体・3名体制／cost-model.md §10-4）。

### 7-4. 工数を25分に圧縮した場合

```
生産上限 = 7,200 ÷ 25 = 288体/月・人
加重粗利 = ¥5,489/体（工数削減分 ¥1,288 が丸ごと粗利に乗る）
1名あたり月間粗利 = 288 × 5,489 = ¥1,580,913
→ 1名で他固定費 ¥580,000 を余裕でカバー
→ 営業利益 ≒ ¥650,900/月、売上 約336万円/月に対し 営業利益率 約19%
```

**工数55分 → 25分の圧縮だけで、営業利益が月2万円から65万円に変わる。** この事業で議論すべきは価格でもマーケティングでもなく、この30分である。

### 7-5. 工数を下げるための具体策（Phase 0 で検証する）
1. **撮影ガイドの強制**: 正面・バストアップ・無地背景・十分な照度。ガイド外の写真は自動リジェクト。難ケース比率20%→8%に下げる（推定）
2. **ポーズテンプレート方式**: 全身を自由生成せず、頭部のみAI生成し、既製のリギング済みボディに接合。**これが最も効く**（推定で工数55分→20分）が、「そのまんまの自分」感は落ちる。トレードオフの意思決定が必要
3. **自動リトポロジー + 肉厚チェックの自動化**: 最小肉厚0.8mm未満の部位を自動検出・自動膨張。ツール導入で10〜15分削減（推定）
4. **NGパターンのフロント側検知**: 眼鏡・複雑な髪型・複数人・ペットとの合成は、アップロード時点で「追加料金」または「非対応」を提示
5. **バッチ処理**: 個別出力をやめ、1プレート20体まとめ出力。造形の段取り固定費 ¥600/体 → ¥200/体（推定）

## 8. リスクと対策

| # | リスク | 発生確率 | 影響度 | 対策 |
|---|---|---|---|---|
| 1 | **AI生成モデルの修正工数が想定を超える（律速）** | 高 | 致命的 | Phase 0で全件実測。45分を超えるならポーズテンプレート方式へ転換。工数KPIを週次で経営指標として管理 |
| 2 | **印刷歩留まり／不良再制作** | 高 | 大 | 不良率10%を原価に引当済み（初期は15%想定）。出力前の自動肉厚チェックを必須ゲートに。出力業者は2社以上に分散 |
| 3 | **「似ていない」クレーム** | 高 | 大 | **決済前に3Dプレビューで顧客承認を取り、承認をログに残す**（rakushumiも同方式）。承認後の「似ていない」返品は不可と規約に明記。ただし造形不良は無償再制作 |
| 4 | **水中設置での剥離・変色・生体への影響** | 中 | 致命的 | 検証完了まで「水中可」と広告しない。生体安全性は第三者試験を検討。免責ではなく検証で潰す |
| 5 | **個人情報・肖像権**（顔写真） | 中 | 致命的 | 顔写真は要配慮情報に準じて扱う。①用途限定・保存期間を明示（納品後90日で自動削除）②第三者提供なし③**未成年の被写体は保護者の個別同意を必須とする**④生成モデルの学習利用は行わない旨を明記⑤外部API（Meshy等）への送信を利用規約に明示 |
| 6 | **AI生成品質のばらつき** | 高 | 中 | 撮影ガイドの強制。品質を「A/B/C」で内部判定し、C判定は着手前に顧客へ再撮影を依頼（工数の無駄打ちを防ぐ） |
| 7 | **繁忙期の生産キャパ不足**（クリスマス・年末年始） | 高 | 大 | ①受注上限を設けて表示（「今月あと○体」）②繁忙期は納期を6週間に延長して明示③外部の3DCGフリーランスを閑散期に育成しておく④繁忙期前に受付枠を先出しして需要を平準化する |
| 8 | **競合の価格攻勢**（ミニチュアイメージ ¥2,980、FigMee ¥9,000） | 高 | 大 | 価格で戦わない。防水+水槽スケール+店舗網の3点に集中。価格改定するなら値下げではなくSの廃止・値上げ（¥9,800）を検討 |
| 9 | **観賞魚器具市場の縮小（3年平均 -2.1%）** | 確定 | 中 | 市場拡大に依存しない計画にする。既存の愛好者の財布内シェアを取る戦略（レイアウト小物の予算を奪う） |
| 11 | **外部API（Meshy）の値上げ・仕様変更・終了** | 中 | 中 | 原価に占める比率は¥250/体と小さく直接影響は限定的。ただし品質変動は工数に直撃する。代替（Tripo, Hyper3D, 自社Fine-tuning）を常時ベンチマーク |
| 12 | **店舗バックの不正・帰属争い** | 中 | 小 | 店舗別のユニークQR/クーポンコードで帰属を機械的に確定。手作業の帰属判定はしない |

## 9. 意思決定が必要な論点（親エージェント／経営判断待ち）

1. **Sサイズ ¥7,800 を維持するか、¥9,800に上げるか、廃止して「S+台座+防水セット ¥10,500」に一本化するか** → 一本化を推奨
2. **ポーズテンプレート方式（頭部のみAI生成）に倒すか、フルAI生成にこだわるか** → 事業成立性を優先するならテンプレート方式
4. **店舗バック15%を全プラン一律にするか、S除外／料率変更するか** → S除外を推奨
6. **初年度の運転資金 約1,340万円（推定）を確保できるか** → 確保できないなら、Phase 0 の工数実測結果が出るまで Phase 1 に進まない
