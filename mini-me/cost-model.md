**実測（公開価格）**

**推定（1受注あたりの試行回数）**
```

  無料プレビュー生成（未決済ユーザー分の按分）  1.5回
  本番生成                                     1.0回
  品質NGによるリトライ                         1.5回
  ────────────────────────────────

apiCost = 4.0回 × ¥62 = ¥248 ≒ ¥250
```

## 3. モデル修正の人手工数 ★最重要項目

AI生成メッシュはそのままでは印刷できない。実務上、以下がほぼ毎回必要になる（推定・一般的な3Dプリント前処理の知見に基づく）。

| 作業 | 内容 | 目安時間 |
|---|---|---:|
| メッシュ健全化 | 非多様体エッジ・穴・自己交差の除去、リトポロジー | 5〜15分 |
| 肉厚補正 | 最小肉厚0.8mm未満の部位（指・眼鏡のツル・髪の毛先・服の裾）を検出して膨張 | 5〜20分 |
| 破綻部位の再造形 | AI が潰した手指・耳・髪型のシルエット修復 | 5〜40分 |
| 台座接合・自立性確保 | 重心確認、接地面の平坦化、台座とのブーリアン | 3〜10分 |
| テクスチャ補正 | UV の破綻修正、肌色・服の色ズレ補正 | 3〜20分 |
| 出力向き・サポート設計 | 造形方向決定、サポート痕が顔に出ないよう調整 | 3〜10分 |
| **合計** | | **24〜115分** |

**ケース分布と加重平均（推定）**
```
良好ケース（正面バストアップ・鮮明・単純な服装）     30% × 20分 =  6.0分
標準ケース                                         50% × 45分 = 22.5分
難ケース（複雑な髪型・眼鏡・小物・低解像度・複数人） 20% × 120分 = 24.0分
────────────────────────────────────────────────────────
editMinutes = 52.5分 → 安全側に丸めて 55分/体
```

```
editCost = editMinutes ÷ 60 × hourlyRate
         = 55 ÷ 60 × 2,500
         = ¥2,292/体
```

> **この55分という数字が本事業の最大の不確実性。** Phase 0（PoC）で50件を全件ストップウォッチ計測し、中央値・第3四分位を実測すること。中央値が45分を超える場合、価格・体制・サービス設計のいずれかを見直す必要がある。

> - 粗利（オプションなし・直販）: S ¥2,057 → ¥2,102（26.3%→26.9%）／ M ¥5,422 → ¥5,570（43.9%→45.1%）／ L ¥8,547 → ¥8,933（47.5%→49.6%）
> - 標準シナリオ月次 売上総利益: ¥666,960 → 約 ¥691,300（**+約¥24,300/月**）
>
> **つまり本モデルは、この点については保守側（原価を高く見積もる側）に振れている。** DMM への発注時に税区分を確認し、確定次第このパラメータを更新すること。

根拠: 1個ずつの単発発注では最低造形料金・プレート占有・梱包の固定費が発生する。

## 10. 計算式の完全定義（`pl-simulation.html` と同一）

### 10-1. BtoC 1体あたり

> **税区分の前提（§1 の原則を再掲）**: 売上は `netRevenue = grossIncl ÷ 1.1` で税抜化する。**原価 c1〜c8（および §10-2 の c12）はすべて税抜額で与える** — 式の中で 1.1 で除していないのはそのためであり、税込額を入力すると原価が約9%過大計上になる。唯一 **c9 決済手数料だけは税込総額（grossIncl）に対して課金される**ため、税込ベースで計算するのが正しい。

```
plan ∈ {S, M, L}
attachBase   = 台座付帯率   (0〜1)
attachWater  = 防水付帯率   (0〜1)
shopRatio    = 実店舗経由比率 (0〜1)

── 売上 ──
optionIncl  = attachBase × 1200 + attachWater × 1500
shipIncl    = (plan === 'L') ? 0 : shipRevenue          // = 800
grossIncl   = price(plan) + shipIncl + optionIncl        // 税込総額
netRevenue  = grossIncl ÷ 1.1                            // 税抜売上（PLの売上高）
backBase    = (price(plan) + optionIncl) ÷ 1.1           // 店舗バック算定基礎（送料を除く税抜）

── 原価 ──
c1  AI生成API        = apiCost                                    // 250
c2  システム          = systemCost                                 // 80
c3  モデル修正工数     = editMinutes ÷ 60 × hourlyRate
c4  造形外注          = printFixed + printPerCm3 × vol(plan)
c5  仕上げ・検品       = finishCost                                 // 500
c6  オプション原価     = attachBase × baseOptCost + attachWater × waterOptCost
c7  梱包資材          = packCost                                   // 270
c8  配送実費          = shipCost                                   // 750
c9  決済手数料        = grossIncl × stripeRate                     // 3.6%
c10 実店舗バック       = backBase × shopBackRate × shopRatio        // 15% × 経由比率
c11 不良再制作引当     = (c3 × 0.30 + c4 + c5 + c6 + c7 + c8) × defectRate

costTotal   = c1 + c2 + c3 + c4 + c5 + c6 + c7 + c8 + c9 + c10 + c11
grossProfit = netRevenue − costTotal
grossMargin = grossProfit ÷ netRevenue
```

### 10-2. 月次PL

```
btocUnits    = ordersPerMonth
totalUnits   = btocUnits

売上高（税抜）  = Σ_plan (btocUnits × mix(plan) × netRevenue(plan))

売上原価       = Σ_plan (btocUnits × mix(plan) × costTotal(plan))

売上総利益     = 売上高 − 売上原価

固定費（販管費）= opsHeadcount × salaryOps      // 3Dオペレーター人件費
                + salaryOther                   // CS・管理
                + adFee                         // 広告宣伝費
                + sysFee                        // システム・SaaS固定費
                + officeFee                     // 地代・その他

営業利益       = 売上総利益 − 固定費
```

### 10-3. 生産キャパシティ

```
requiredMinutes = btocUnits × editMinutes
capacityMinutes = opsHeadcount × opsMinutesPerHead      // 7,200分/人
utilization     = requiredMinutes ÷ capacityMinutes

utilization > 1.0 の場合、その受注数は物理的に処理できない（納期遅延・外注・人員追加が必要）
```

### 10-4. 損益分岐点（BEP）

構成比・オプション付帯率を固定したまま、受注数だけをスケールさせる。
**人員は必要数に自動追随させる**（人員が増えると固定費が増えるため反復計算が必要）。

```
blendedGP(1受注単位) = 売上総利益 ÷ btocUnits        // 1件あたり粗利

繰り返し（最大20回、収束するまで）:
    fixedCost  = headcount × salaryOps + salaryOther + adFee + sysFee + officeFee
    bepOrders  = ceil(fixedCost ÷ blendedGP)
    needMin    = bepOrders × editMinutes
    newHead    = max(1, ceil(needMin ÷ opsMinutesPerHead))
    if newHead === headcount: 収束 → 終了
    headcount  = newHead
```

**標準前提での計算結果**
```
標準シナリオ（月150体、S40/M40/L20、店舗経由30%、台座40%、防水25%）
  ユニット粗利       S ¥1,983（23.1%）／ M ¥5,143（39.1%）／ L ¥7,981（42.5%）
  加重粗利           ¥4,446/体
  売上高（税抜）      ¥1,867,500/月
  売上総利益         ¥666,960/月（粗利率 35.7%）
  必要工数           150 × 55 = 8,250分 → 必要人員 2名
  固定費             2 × 350,000 + 150,000 + 300,000 + 30,000 + 100,000 = ¥1,280,000
  営業利益           666,960 − 1,280,000 = ▲¥613,040

  BEP 反復（1件あたり粗利 ¥4,446）:
    2名前提 → 固定費 ¥1,280,000 → BEP 288体 → 必要工数 15,840分 → 3名必要
    3名前提 → 固定費 ¥1,630,000 → BEP 367体 → 必要工数 20,185分 → 3名（上限21,600分）で収束
  → BEP = 月367体（3名体制・稼働率93.4%）

  ※ オプション付帯をゼロと置いた場合（加重粗利 ¥4,202/体）:
     BEP = 月388体（3名体制・稼働率98.8%）
```

**この結果の意味**: 標準前提でも3名がほぼフル稼働（93.4%）してようやく損益分岐であり、繁忙期・有給・不良対応の余地が無い。オプション付帯を織り込まなければ稼働率98.8%となり、実質的に到達不能。**現前提のままでは事業として成立しない。**

> **BEP を語るときは必ず前提2点（オプション付帯率／店舗経由比率）を明示すること。** 「BEP 月367体」と「月388体」は同一モデルの出力であり、違いは前提だけである。

## 11. 感度分析（推定）

標準シナリオ（月150体・2名体制・営業利益 ▲¥613,040）を基準に、各パラメータを単独で動かしたときの月次営業利益への影響。

| パラメータ | 基準 | 変化 | 営業利益への影響（月次・推定） |
|---|---:|---|---:|
| **修正工数** | 55分 | **→ 25分** | **+¥193,125**（BtoC150体 × ¥1,288）※さらに生産キャパが2.2倍になる効果が別途 |
| **ミックス** | S40/M40/L20 | **→ S20/M45/L35** | **+¥158,600** |
| 広告費 | ¥300,000 | → ¥150,000 | +¥150,000 |
| 修正工数 | 55分 | → 75分 | ▲¥128,750 |
| 造形単価 | ¥260/cm³ | → ¥342（値引き交渉が不成立） | ▲¥73,700 |
| 店舗経由比率 | 30% | → 50% | ▲¥53,400 |
| 不良率 | 10% | → 15% | ▲¥37,200 |
| 台座付帯率 | 40% | → 70% | +¥17,300 |

**読み方**: 効くのは順に ①修正工数 ②ミックスの上位シフト（L比率を上げる）③広告費 の3つ。
造形単価・不良率・オプション付帯率は、いくら改善しても月数万円レンジにしかならない。
**「3Dプリント代を安くする交渉」に時間を使うより、「Lサイズを売る」「工数を半分にする」ほうが桁違いに効く。**
なお修正工数の圧縮は、営業利益への直接効果（+¥193,125）よりも、**生産キャパが131体/月 → 288体/月に増える効果のほうが本質的に大きい**（BEPを超えて売れるようになる）。

## 13. この原価モデルの弱点（正直に書く）

1. **修正工数55分は実測ではなく推定。** 本モデルで最も影響が大きい数字が、最も根拠が弱い。Phase 0 の実測前に投資判断をしてはいけない。
2. **造形体積の22%という係数も推定。** 実際のメッシュで計測すれば±30%はぶれる。L サイズの造形費 ¥3,980 は ¥3,000〜¥5,200 のレンジで見るべき。
3. **ボリュームディスカウント25%は交渉前の希望的観測。** 月100個規模で本当にこの率が取れるかは未確認。取れなければ造形単価は ¥342/cm³ のままで、L の粗利率は 47.5% → **41.0%**（粗利 ¥8,547 → ¥7,374）に落ちる。造形費 c4 が ¥3,980→¥5,046 に上がるだけでなく、不良再制作引当 c11 も ¥619→¥725 に連動して増えるため、差は単純な造形費差より大きくなる。
4. **返品・返金コストを原価に入れていない。** 不良再制作率10%とは別に、全額返金となるケース（推定2〜3%）の売上取消と決済手数料の非返還が発生する。粗利率で約2ポイントの下振れ要因。
5. **顧客サポートの工数を固定費（CS人件費）に押し込んでいる。** 実際は受注数に比例して増えるため、規模拡大時に固定費が想定より膨らむ。
6. **在庫リスクは考慮していない。** 受注生産のため原則不要だが、化粧箱・台座・コーティング剤の最低ロット仕入れによる在庫は発生する（推定 初期30万円）。
7. **仕入原価の税区分が一部未確認。** §1 の原則どおり c1〜c8・c12 は税抜として積んでいるが、原価の元ネタ（DMM 公開価格、ヤマト法人単価、梱包資材、コーティング材）は税抜／税込の別が明示されていないものがある。仮にこれらが税込表示だった場合、原価は約9%過大計上となり、粗利は**過少**に出ている（L で約¥490/体、標準ミックス月150体で約¥5万円/月）。**方向としては保守側の誤差**だが、発注時に全項目の税区分を確認して確定させること（§4-2 の注記）。
