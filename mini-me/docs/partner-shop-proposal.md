# 提携店舗のご案内 ── チラシを置くだけで、売上の15%が店舗収益に

**ちいさなじぶん店舗提携プログラム**
運営: 株式会社企画7課
資料バージョン: 1.0（2026-07-29）

対象: アクアリウムショップ・熱帯魚店・園芸店・爬虫類/テラリウム専門店 の店長さま

---

## 1. 結論：店舗さまの負担はゼロ、収益だけが増えます

| 項目 | 店舗さまの負担 |
|---|---|
| 仕入れ・在庫 | **ゼロ**（商品を仕入れる必要がありません） |
| 初期費用・月額費用 | **ゼロ** |
| 接客・販売作業 | **ゼロ**（お客さまはWebで直接注文します） |
| 発送・梱包 | **ゼロ**（当社から直接お客さまへ発送） |
| 在庫の売れ残りリスク | **ゼロ** |
| **店舗さまの収益** | **店舗経由の注文の、税抜売上の 15%** |

やっていただくのは、**レジ横にチラシを置く／ポスターを貼る**、これだけです。

## 2. ちいさなじぶん とは（30秒で）

お客さまがスマホの写真をWebにアップロードすると、AIが3Dモデルをつくり、
**ミニチュアフィギュアが3Dプリントされて自宅に届く**サービスです。

水槽やテラリウムの中に「自分」「家族」「ペット」を置ける、というのが最大の売りです。
防水コーティングオプション（+¥1,500）で、水中設置にも対応します。

サイズは 40mm / 65mm / 100mm の3種。水槽レイアウトには 40mm が最適です。

**なぜアクアリウムショップと相性がいいか**
- 水槽を持っている＝レイアウトにお金と時間をかける趣味層。単価の高い商品が通ります
- 「自分が水槽の中にいる」写真はSNSで伸びやすく、投稿がそのまま店舗の宣伝になります
- 季節ごと・ポーズ違いでリピートが起きます（1体で終わらない）

```
※ 送料（¥800）はバック計算の対象外です
※ 円未満は切り捨て
```

**計算例（B：標準／月10件の場合）**
`¥15,500 ÷ 1.1 = ¥14,090（税抜・切り捨て）`

`¥2,113 × 10件 = ¥21,130（月間）`
`¥21,130 × 12ヶ月 = ¥253,560（年間）`

> **注記（重要）**：上記の件数はサービス設計上の想定であり、実績に基づく数値ではありません（推定）。

> 「必ずこれだけ稼げる」という保証ではありません。在庫リスクがないため、件数が0でも店舗さまの損失は発生しない、という点が本プログラムの本質です。

## 4. 導入手順（4ステップ）

### STEP 1 ── 専用コードの発行（当社／申込から3営業日）
お申し込みいただくと、店舗さま専用の **紹介コード**（例：`AQUA-1234`）を発行します。
店舗名から連想しやすい文字列でご指定いただくことも可能です。

### STEP 2 ── チラシ／ポスターの設置（店舗さま）
当社から**無償**で以下をお送りします。
- A5チラシ（100枚〜、コード印字済み・追加分も無償）
- A2ポスター（1枚、コード印字済み）
- レジ横用の卓上POP（1台）
- 店内ディスプレイ用のサンプルフィギュア（1体・貸与）※希望店舗のみ

置き場所のおすすめ：**レジ横**、**水草／レイアウト素材コーナー**、**流木・石の売り場**。
水槽レイアウトを検討している最中のお客さまの目に入る位置が最も反応します（推定）。

### STEP 3 ── お客さまがWebで注文
お客さまがチラシのQRコードからサイトへアクセスし、注文フォームの
**「紹介コード」欄に店舗コードを入力**して注文します。

**店舗さまは接客も、説明も、注文代行も不要です。**
「これ、水槽に自分入れられるやつなんですよ」と一言添えていただけると成約率は上がりますが、必須ではありません。

### STEP 4 ── 精算（月末締め・翌月末払い）
当月1日〜末日の店舗コード付き注文を集計し、**翌月末日**に指定口座へお振込みします。

```
[チラシのQRコード] → サービスサイト
                        ↓
       写真アップロード → 3Dプレビュー確認
                        ↓
              注文フォーム
              ┌─────────────────────────┐
              │ お名前　　　  [          ] │
              │ ご住所　　　  [          ] │
              │ 紹介コード　  [ AQUA-1234 ] │ ← ここに店舗コードを入力
              └─────────────────────────┘
                        ↓
                  Stripeで決済
                        ↓
       店舗コード付き注文として当社側に記録される
```

- チラシのQRコードには **コードがあらかじめ埋め込まれています**。QRから入ったお客さまは、入力欄に自動でコードが入ります（手入力の手間なし）
- 手打ちでの入力にも対応。「チラシを持ち帰って、後日PCから注文」というケースも取りこぼしません
- 有効期限はありません。半年後に注文されても、店舗さまのバックは発生します
- **店舗さま専用の管理ページ**（Web）を発行します。今月の注文件数・確定バック額をいつでも確認できます

## 7. 想定されるご質問・ご懸念

### Q1.「水槽の中に樹脂の置物を入れて、魚に害はないのか？」

**A. 防水コーティング品は水中設置を想定した仕様ですが、当社は「短期の設置」を推奨しており、長期常設は推奨していません。**

- 素材は光造形（UVレジン）で造形し、完全硬化させたうえで水性・溶剤系のクリアコートで封止します（推定仕様・最終仕様は【要記入：素材/塗料の確定仕様】）
- 未硬化レジンは水生生物に有害です。当社では二次硬化を完了させた製品のみを出荷します
- ただし、**「絶対に安全」とは申し上げません。** 生体の入っている水槽への設置は、お客さまの判断と自己責任でお願いする形をとっており、チラシ・サイトにもその旨を明記しています
- 撮影用に一時的に入れる、生体のいないレイアウト水槽に入れる、という使い方を主に案内しています

→ **店舗さまが「大丈夫です」と保証する必要はありません。**「メーカーがサイトで説明してるので読んでみてください」で完結します。

### Q2.「お客さんに売り込む手間がかかるのでは？」

**A. 売り込みは不要です。チラシを置くだけで成立する設計にしています。**

- お客さまはQRコードからご自身で完結します。店員さまの説明は不要です
- 価格説明も不要（チラシに全価格を記載しています）
- 「これ何ですか？」と聞かれたときのために、**A4一枚の店員さま向け説明シート**をお渡しします。それ以上のことは覚えていただかなくて構いません
- 注文の代行・レジでの取り扱いは**ありません**。店舗さまのレジ締めに影響しません

### Q3.「クレームが来たら、うちが受けることになるのでは？」

**A. 商品に関する責任・クレーム対応はすべて当社が負います。店舗さまは一切対応不要です。**

- 販売主体は**株式会社企画7課**です。店舗さまは紹介のみで、売買契約の当事者になりません（この点は申込書に明記します）
- チラシ・ポスター・サイトのすべてに当社の問い合わせ先を記載しています
- 万一お客さまが店頭で苦情を言われた場合は、**「メーカーに直接お問い合わせください」と当社の連絡先カードをお渡しいただくだけで結構です**。専用のカードもお送りします
- 店舗さまに損害が及ぶような事態が起きた場合の責任範囲は、申込書の条項で明記します

### Q4.「お客さんの個人情報は、うちを経由するのか？」

**A. 一切経由しません。** 店舗さまは個人情報を預かりません。

- お客さまの氏名・住所・写真・決済情報は、すべてお客さまから当社へ直接送信されます
- 店舗さまの管理ページに表示されるのは **注文件数・注文日・商品・バック額のみ**です。氏名や住所は表示しません
- したがって、店舗さま側で個人情報保護の追加対応をしていただく必要はありません

### Q5.「契約に縛られるのでは？ 途中でやめられるのか？」

**A. いつでもやめられます。違約金も、最低契約期間もありません。**

- 契約期間の定めなし。**メール1通でいつでも解除**できます（当社側からの解除も同条件）
- ノルマ・最低販売数はありません。0件でもペナルティはありません
- 他社の類似サービスとの併売も自由です（独占契約ではありません）
- 解除後も、解除前に発生した注文のバックは通常どおりお支払いします
- チラシ・ポスターは解除時に破棄していただくだけで結構です（返送不要）
