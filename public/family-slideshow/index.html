📷 家族フォトスライドショー の使い方

Google ドライブの共有フォルダに入れた写真を、テレビ・iPad・PC で全画面スライドショー表示するアプリです。フォルダに写真を追加するだけで、次回読み込み時に自動で反映されます。

1. Google ドライブ側の準備

  • Google ドライブに写真用フォルダを作り、家族と共有（編集者）します。
  • フォルダを右クリック →「共有」→「一般的なアクセス」を 「リンクを知っている全員（閲覧者）」 にします。
  • フォルダ URL（https://drive.google.com/drive/folders/...）をコピーします。
  • iPhone の HEIC 写真もそのまま入れて OK です（Google 側で JPEG に変換して表示します）。

2. Google API キーの発行（初回のみ・無料）

  • Google Cloud Console でプロジェクトを作成します。
  • 「API とサービス」→「ライブラリ」→ Google Drive API を有効化します。
  • 「認証情報」→「認証情報を作成」→「API キー」を発行します。
  • 推奨：キーの制限で「HTTP リファラー」に https://cc-dev-ps7.web.app/* を追加し、「API の制限」で Google Drive API のみに絞ります。

3. このアプリの設定

  • 画面をタップ → 右上「⚙️」→ フォルダ URL と API キーを入力 →「保存して開始」。
  • 設定画面の「共有リンク」をコピーして家族に送ると、相手は設定不要で同じスライドショーを見られます。

操作方法

  • 画面タップ / マウス移動：操作ボタンを表示（数秒で自動的に隠れます）
  • ‹ › または ← → キー：前 / 次の写真
  • ⏸ / ▶ または スペースキー：一時停止 / 再開
  • ⛶ または F キー：全画面表示
  • 🔄：フォルダを再読み込み（追加した写真を反映）。10分ごとに自動でも再読み込みします。
  • 画面のスリープは自動で防止します（対応ブラウザのみ）。

iCloud について

iCloud Drive には Web から読める公開 API がないため、現バージョンでは対応していません。iPhone の写真は「Google ドライブ」アプリからアップロードするか、iPhone の設定で Google フォト / ドライブへの自動バックアップを使うのが簡単です。iCloud「共有アルバム」の公開リンク対応は今後の検討項目です。

トラブルシューティング

  • 「写真が見つかりません」：フォルダの共有設定が「リンクを知っている全員」になっているか確認。
  • 「API キーが無効」：Drive API が有効化されているか、リファラー制限が正しいか確認。
  • 写真が表示されない（黒いまま）：ファイル自体も共有されている必要があります。フォルダ共有後に追加した写真は自動で継承されます。
