⚙ 保護者メニュー

再生する YouTube 動画・チャンネル・再生リスト（1行に1つ貼る）

動画URL（youtu.be / Shorts / 動画IDも可）のほか、チャンネルURL（@ハンドル・/channel/UC…）や再生リストURL（list=…）も貼れます。チャンネルは最新 本を取り込みます（保存し直すと最新に更新）。

視聴の記録

どの動画を何回・何分見たか、曜日・時間帯ごとの傾向をまとめて見られます。

共有コード（別の端末でも同じセットを使う）

このセットのコード
------
別の端末で ⚙ → コードを入力、QR を読み取る、または URL の後ろに ?code=コード を付けて開く

動画を保存すると共有コードが発行されます。

キーボードのゾーン（どこを叩いても大丈夫）

キーボードの左のほう＝まえの動画、まんなか＝つぎの動画、スペース＝止める/うごかす、右のほう＝右に並んだ候補（上の段ほど上の候補）。

まえ つぎ 止める/うごかす 候補① 候補② 候補③ 候補④

Ctrl / Alt / ⌘ を押しながらのキーはブラウザに渡します（保護者用）。矢印：← まえ／↑ 候補①／→ 候補②／↓ 候補③。テンキーも右側ブロック扱いです。動画が終わると自動で「つぎ」に進みます。

全画面

PC ではキーを叩くと自動で全画面になります（ブラウザのボタンやタブに触れないように）。　戻すときは Esc 長押し、または ⛶。

タッチ

動画の真ん中をタップ＝止める/うごかす、左端＝まえ、右端＝つぎ、右の候補をタップ＝その動画。左右スワイプでも進めます。
