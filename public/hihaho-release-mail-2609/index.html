動画のつながりを可視化する「ビデオフロー」、キーボード・スクリーンリーダー対応、質問タイマーの全ユーザー公開など、hihahoの2026年9月アップデートをご紹介します。

2026年9月 リリースのお知らせ
 

こんにちは、hihaho日本総代理店のスプライングローバルです。

このたび、インタラクティブ動画プラットフォーム『hihaho（ヒハホ）』の2026年9月アップデートがリリースされました。

今回のアップデートでは、動画同士のつながりを図で確認できる「ビデオフロー」の新搭載に加え、キーボード・スクリーンリーダー対応の大幅強化、視聴者一人ひとりの行動をたどれるセッション結果ページの刷新、質問タイマーの全ユーザー公開（ベータ）などに対応しました。

リリースノートの詳細はこちら

今回のアップデートのポイント
Studio 動画同士のつながりを可視化するビデオフロー、ホバーでツールチップ、全カラーピッカーにスポイト
アクセシビリティ キーボード操作・スクリーンリーダー対応が大幅向上。画像に説明文（代替テキスト）を設定可能に
統計 セッション結果ページを刷新し、視聴者一人ひとりの行動を時系列で表示。チャプター別クリック数も
質問 質問タイマーが全ユーザーにベータ公開。画像問題で複数正解、AI採点される質問にはAIマークを表示
AI 動画に「目的」と「学習目標」を設定すると、AIがそれに合わせて問題作成・採点。質問の音声読み上げにも対応
プレイヤー iPhone / iPad での JW Player 動画の再生が安定。セッション終了時の統計送信もより確実に
動画のつながりをひと目で把握できる「ビデオフロー」
導入動画 → 分岐A / 分岐B → まとめ
⚠ 到達できない動画  も自動で発見

フォルダ内の動画が「動画終了時アクション」でどう繋がっているかを図で確認できます。動画を選択すると関連する接続がハイライトされ、視聴者が到達できない動画も見つけられます。矢印のドラッグや右クリックでリンクを削除でき、Undoで元に戻すことも可能です。

すべての人のためのプレイヤー（アクセシビリティ強化）
K  再生 / 一時停止 C  字幕
J L  スキップ ?  ショートカット一覧

プレイヤーがキーボードで快適に操作できるようになりました。スクリーンリーダーが各ボタンとその状態を読み上げ、字幕言語の変更・質問の結果・最終スコアもアナウンスします。画像ライブラリの画像に説明文を設定すると、インタラクション・質問・回答内で読み上げられます。

セッション結果ページのデザインを刷新しました。合否・スコア・どこまで進んだかがタイルでひと目でわかり、タイムラインでは視聴・再視聴・スキップ・クリックした内容を時系列で確認できます。一覧に戻らずに前後のセッションへ移動することも可能です。

質問タイマーが全ユーザーに開放 BETA

これまでhihahoスタッフ限定だった、質問のカウントダウンタイマーが使えるようになりました。質問エディタの「Assessment」タブで個別に設定するほか、動画・フォルダ単位でのデフォルト設定も可能です。リング表示／小さなピル表示を選べ、最長30分まで設定できます。

その他の主な改善
質問とAI
・画像問題で複数の正解を設定可能に（正解ごとに配点）
・自由記述問題に画像を表示可能に（モダンレイアウト）
・AI採点の厳しさを自由記述ごとに設定可能に
Studioエディタ
・リンク・テキスト・画像などにホバーでツールチップを表示
・すべてのカラーピッカーにスポイト（Chrome / Edge）
・YouTube・Vimeo等も含め、任意の動画のソースをアップロードで差し替え可能に
プレイヤー
・新しい自動再生オプション（音声付きを試み、ブロック時はミュート再生に切替）
・プレイヤーが読み込めない場合は再読み込みを促すメッセージを表示
・動画下の共有ボタンを刷新（Twitter は X に）
自動字幕
・AssemblyAI が既定の字幕サービスに（高速・最大5GBに対応）
・ブランド名・専門用語を登録すると新規字幕で正しく表記（AI音声読み上げプラン）
LMS・インテグレーション
・全動画に JSON 版（プレイヤーURL末尾に .json、正解は含まれません）
・LTI 1.3 の接続ガイドを公開。同一校内ネットワークからクラス全員で同時視聴が可能に
・厳格なLMSでの SCORM 開始時エラーを解消

このほか、既存機能の改善・不具合修正など全項目は、リリースノートにてご確認いただけます。
