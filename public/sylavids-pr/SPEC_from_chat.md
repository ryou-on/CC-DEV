# Sylavids プロモーション動画 制作引き継ぎ

## 依頼と到達点
- 依頼者：表ロビー純平／スプライングローバル
- 元資料：同梱の「Sylavidsカタログ_企業向け_v5.9.pdf」（9ページ）
- 目的：法人の営業・研修担当者に、既存資料を説明動画へ変える価値を30秒で伝える。
- 納品仕様：横1920×1080、30fps、約30秒、H.264 MP4、yuv420p、faststart。
- この引き継ぎ書はユーザーがClaude Codeへ渡すためのもの。自動送信・公開・有料サービス利用は行っていない。
- 最初の確認版は音声なしのモーショングラフィックス。下記ナレーション案は未収録。完成版と混同しない。

## デザイン
白・ごく淡いミントを基調に、正式ロゴの緑をアクセント。カタログの端正で余白のあるトーンを継承する。可読性を優先し、画面全体を細かい説明で埋めない。派手な3D、強いグラデーション、装飾の乱用を避ける。
- ロゴ：assets/logo.png。元PDFの正式ロゴをそのまま使う。文字を打ち直して代替しない。
- 実画面：assets/editor.png、import.png、play.png。架空UIは生成しない。補助図は「概念図」と区別する。
- カタログ内画面には旧表記「しらびず」がある。無断で描き変えず、外側のブランド表記はSylavidsに統一。
- 日本語見出しは大きく、1場面の主メッセージは1つ。タイトルは60〜100px、補足は32〜44px目安。
- 出入りは0.3〜0.6秒のフェード＋軽い位置移動。強いズーム、点滅、絶え間ない動きを避ける。

## 内容の重要な制約
- 「約3分」は2026年10月の当社実測例で、目標10分・4章17スライドと原稿の下書きまで。音声生成・書き出しは含まない。今回は数字を省く。採用する場合は条件を同じ画面で表示。
- AIの原稿は下書きであり、公開前の確認が必要。完全自動・誤りゼロ・確認不要とは表現しない。
- PowerPointの一部アニメーションは再現できない場合がある。「完全再現」としない。
- 料金・動画作成時間・品質割合は今回は出さない。カタログ記載を現行の保証値として拡張しない。
- 既存資料のデザイン維持、原稿・音声・字幕、変更したスライドの原稿／音声の再生成を主軸にする。
- 自分の声の登録機能は掲載されているが、今回、本人や第三者の声を新規登録・クローンしない。
- Hanaを使用する場合、サービスと声モデル、費用上限、実行許可を確認する。ナレーション案を録音済みと扱わない。

## Claude Codeでの実装案
Remotionまたは既存の動画制作環境を使う。6つの5秒シーンとして分け、定数化した配色・フォント・尺を共有する。ソースPDFとロゴ・画像は保持して非破壊で作業する。同梱render.pyはPython/Pillow＋ffmpegの確認版実装で、動き・構成の参考。変更版は別ファイル名にする。
