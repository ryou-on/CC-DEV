## 共通

- 技術はスナリのライトと同じ。単一 HTML、インライン CSS、末尾の短いスクリプト、Google Fonts、写真なし。
- 骨格は品質基準の10ブロック。業種ごとの差は、ヒーローの形・言い切り・カードの中身・料金の呼び方。
- 差し替え記号: 架空の店名、`XX` の番地、`03-0000-11xx`、料金の「例」、【】の確認項目。
- 提案段階では写真もロゴ画像も入れない（既存カタログと同じ）。納品で写真を足すときの枠だけ、下に書く。

### 写真を足すときの共通ルール（構想）

- 提案中は文字のまま。納品で入れるなら 1 ページ 3 枚まで。
- WebP または JPEG。長辺 1600px 以下、1 枚 200KB 前後。`width` と `height` を指定。
- 人物の顔は同意があるものだけ。通行人、客の後ろ姿の特定、表札が読める近景は使わない。
- 枠の位置は各業種の「写真」を参照。HTML には `img` をまだ置いていない。

### スタンダードへ広げるとき（構想・全業種共通）

`samples/sunali-standard/` と同じく、HTML を分けて1つの CSS を読む。

| ページ | 中身 |
|---|---|
| index | ヒーロー、考え方の要約、各ページへのカード3枚、固定バー |
| story | 考え方の全文と提供内容 |
| menu | 品書きまたは料金の全件 |
| news | 本日の札・休業・キャンペーン。無ければページ自体を作らない |
| access | 店舗案内と地図リンク |

プレミアム（構想）は `sunali-premium` に合わせ、日英切替・予約リクエスト・FAQ を足す候補。予約の送信先が無い店では作らない。ライトの下書きにはフォームを置いていない。

## 飲食 — 昼餉 まどべ

昼定食。夜営業のラーメン（麺屋たろう）とも、スパイスのビストロ（スナリ）とも並べたときに別の店に見えること。

### ページ構成（動作確認済み）

ヒーローは左に一句、右に「本日の札」。考え方案は出汁とご飯の2枚。品書きは看板定食＋定番。数字は営業の事実だけ（開店時刻、終了、席数）で、来客数は置かない。

### 配色

| 役割 | 色 | 意図 |
|---|---|---|
| 地 | `#f3eee4` | 昼間の木のテーブル |
| 文字 | `#241c14` | 墨に近い茶 |
| 弱い文字 | `#5c5146` | 説明。地に対して読める濃さ |
| アクセント | `#9a3b24` | 柿渋。ボタンと価格 |
| 第二 | `#2f5d45` | 苔。ラベルと札の線 |
| 線 | `#e0d5c6` | 区切り |

書体: 見出し Shippori Mincho B1、本文 Zen Kaku Gothic New。

### 必須セクション

- 昼だけ、という営業の限定
- 看板定食（汁・ご飯・香の物が付く旨）
- 税込と、ご飯がなくなり次第終わること
- 支払い方法の例
- 最寄りと徒歩分数（納品時に実測）

### 写真方針（構想）

- 足すならヒーロー右の札を、自然光の俯瞰1枚に差し替える。湯気と器。人の手は入ってよいが顔は入らない。
- 一覧の各行には写真を付けない。文字の価格表のままがこの業種の美しさ。
- 夜の暗い皿、フィルターの強い赤、ストック写真の笑顔は使わない。

## 美容 — 髪処 ルミエル

静かな2席の美容院。にぎやかなクーポン集にしない。

### ページ構成（動作確認済み）

ヒーローは店名を大きく、その下に「2席・完全予約・駅からの分数」。メニューはカット / カラー / ケア。スタイリストは名前と担当だけ。予約は電話。ウェブ予約フォームはプレミアム構想。

### 配色

| 役割 | 色 | 意図 |
|---|---|---|
| 地 | `#f7f4f0` | 生成りの壁 |
| 文字 | `#241f22` | ほぼ墨 |
| 弱い文字 | `#5c5458` | 説明 |
| アクセント | `#6d2e3a` | ワインレッド。ボタンと価格 |
| 第二 | `#8c7355` | 真鍮。英字と細線 |
| 線 | `#e4dcd4` | 髪の毛のような細い区切り |

書体: 見出し Shippori Mincho B1、本文 Zen Kaku Gothic New。英字の極小だけ Cormorant Garamond。

### 必須セクション

- 完全予約か、飛び込み可か
- カット・カラー・トリートメントの起点価格（税込の例）
- 所要時間の目安
- 薬剤は事前申告、という一文
- スタイリスト名（写真なしで成立すること）

### 写真方針（構想）

- 基本は文字のまま。
- 足すならメニューの上に1枚。後ろ姿か、手元とハサミ。正面の顔アップは同意がある場合だけ。
- ビフォーアフターで肌や服が特定される組は使わない。
- ストックの外国人モデル、過度な光沢加工は使わない。

## 整体 — 整体 からだ舎

安心して読めること。効く、治る、とは書かない。

### ページ構成（動作確認済み）

ヒーローは問いかけの一句。続くカードは「こんな日の例」であり診断名ではない。流れは問診・施術・セルフケアの3段。料金は初回と継続。免責の枠を料金の直後に置く。

### 配色

| 役割 | 色 | 意図 |
|---|---|---|
| 地 | `#f3f6f4` | 明るい畳寄りの白緑 |
| 文字 | `#1a2a26` | 深い緑墨 |
| 弱い文字 | `#4d5c56` | 説明 |
| アクセント | `#1e4f46` | 茶室の柱のような緑 |
| 第二 | `#8d7352` | 薄い木。ラベルのみ |
| 線 | `#d5e0db` | 区切り |

書体: 見出し・本文とも Zen Maru Gothic（角を立てない）。数字と英字ラベルだけ IBM Plex Sans JP。

### 必須セクション

- 医療行為ではないこと
- 強い痛み、しびれ、外傷は医療機関へ、という一文
- 初回は問診に時間を取ること
- ボキボキするかしないか（この下書きは「急な矯正はしない」）
- 初回料金と時間、2回目以降
- 予約は電話。保険適用とは書かない（確認できないため）

### 写真方針（構想）

- 院内の明るい全景1枚まで。施術台、植物、窓。
- 施術中の顔、肌の露出、患部のアップは使わない。
- 白衣と聴診器など、医療機関に見える小道具は使わない。
- ビフォーアフターの姿勢写真は、このテンプレでは採用しない。

## 建設 — 大塚工務店

リフォームと小規模の修繕。新築メーカーの豪華写真サイトにしない。図面の線と、短い仕様書。

### ページ構成（動作確認済み）

ヒーローは「必要なところだけ、直す。」の下に、受けられる工事を4行の仕様として並べる。流れは現地・見積・工事・引き渡し。数字は日数の目安で、棟数や創業年は【】に残す。受けない工事を案内表に書く。

### 配色

| 役割 | 色 | 意図 |
|---|---|---|
| 地 | `#f4f2ec` | 図面の余白 |
| 文字 / ボタン | `#1b2330` | 紺墨 |
| 弱い文字 | `#4e5868` | 仕様の注記 |
| アクセント | `#8a4e16` | 焼けた琥珀。ラベルと価格。警告色にはしない |
| 線 | `#d9d3c6` | 薄い罫線 |
| 格子 | `rgba(27,35,48,.06)` | ヒーロー背景の方眼 |

書体: IBM Plex Sans JP に統一。見出しもゴシック。明朝は飲食・美容に譲る。

### 必須セクション

- 受けられる工事（水まわり、内装、店舗の小規模、修繕）
- 受けない工事（大規模新築、マンション一棟、許可外）
- 見積りの前に現地で寸法を取ること
- 工期は天候で前後すること
- 【建設業許可】が確認できるまで番号を書かない
- 対応エリアは納品時に実在の範囲へ直す

### 写真方針（構想）

- 足すなら完了写真2枚まで。外観1、取っ手や框などの詳細1。
- 足場の全景より、終わったあとの静かな写真。
- 表札、車のナンバー、隣家の顔が写るものは使わない。
- before/after は施主の許可があり、番地が特定されないときだけ。標準のライトでは入れない。
