# 業種別テンプレート 品質基準

大塚AIビジネスサポートの「美麗な1ページ」を増やすときの基準。  
基準にした実物は次の2つ。

| サンプル | パス | この基準での役割 |
|---|---|---|
| 麺屋たろう | `public/otsuka-ai-support/samples/menya-taro/index.html` | 世界観・余白・タイポグラフィ・一行の強さ |
| ベンガルビストロ スナリ（ライト） | `public/otsuka-ai-support/samples/sunali/index.html` | 1ページの構成、明るい地、電話までの短さ、表示の軽さ |

延長として見ているもの（今回の下書きの直接の型にはしない）:

- ライトの着せ替え雛形 `templates/light.html`（テーマ切替。業種の中身は薄い）
- スタンダード `samples/sunali-standard/`（5ページ・外部CSS）
- プレミアム `samples/sunali-premium/index.html`（予約・日英・強い演出）

今回の業種別ファイルは、**スナリと同じライト1ページ**に、**麺屋たろうの文字の密度と余白**を足したもの。写真もロゴ画像も置かない。

---

## 1. デザイン

- 店の気配が、ヒーローの第一画面で分かること。色・書体・見出しの言い切りで業種が違うこと。同じ配色の横流しをしない（既存カタログの「1店1テーマ」と同じ考え）。
- 色は CSS 変数に閉じる。地、文字、弱い文字、アクセント、線、カードの6つで足りる。アクセントはボタンと少量の見出しにだけ使い、画面を埋めない。
- 書体は2ファミリーまで。見出し用と本文用。欧文の極小ラベルが要るときだけ3つ目を足してよい（麺屋たろうの Cormorant がこの例）。ウェイトは各2〜3。
- 和文の見出しは `letter-spacing` で空気を作る。本文は 14〜15px、行間 1.9〜2.2。キャッチは短く、説明は2文まで。
- 装飾は CSS とインライン SVG だけ。円、線、格子、札。写真の代わりに「本日の札」「料金の例」など、文字そのものを見せる。
- 角丸・線の太さ・余白のリズムをページ内で揃える。カードを増やして情報を埋めない。セクション間は `clamp` で 56〜90px（ライト）を基本にする。
- 下部の固定バーと、画面端の社内チップが本文に被さらないよう、フッター下に余白を取る。

麺屋たろうから採るもの: 墨と生成りの対比、英字の極小ラベル、点線の価格行、一句の引用。  
採らないもの: 全画面ローディング、縦書きヒーローの使い回し、カウントアップ、重い粒子オーバーレイ。あれはあの店の演出であり、業種テンプレの標準装備にしない。

スナリから採るもの: 明るい紙色、中央または左の短いヒーロー、看板1品＋一覧、店舗テーブル、電話の固定バー。  
採らないもの: モバイルで中身のリンクが消えること（第6節）。

## 2. 構成

ライト1ページの並び。これが業種テンプレの骨格。

1. ヘッダー（店名、ページ内リンク、電話）
2. ヒーロー（業種が分かる一句、店名、主ボタンと副ボタン）
3. 考え方（段落は2つまで）
4. 提供内容（カード 2〜4）
5. 品書きまたは料金（看板1つ＋一覧。税込と「例」を明示）
6. 数字（3つまで。測れない数字は置かない）
7. 一句（店の言葉。架空なら架空と書く。許諾のない口コミは書かない）
8. 店舗案内（表＋地図へのリンク）
9. フッター（店名、電話、制作表記）
10. 画面下の固定バー（電話＋次の行動1つ）

`h1` はヒーローに1つ。セクションは `h2`、カードは `h3`。

複数ページ（スタンダード以上）は、この1ページを分割する。ホームは入口、考え方・メニュー・案内を各ページへ。ナビの名前をライトと揃える。今回の4業種は **ライト1ページを動作確認済み**。複数ページは [industry-briefs.md](industry-briefs.md) の構想。

## 3. コード

- 1店舗1 HTML。スタイルは `<style>`、動きは末尾の `<script>`。ビルドもフレームワークも入れない。
- 先頭に `charset` と `viewport`。`lang="ja"`。`title` と `description` は店名と地域と業種が入る文。
- 社内の下書き・カタログは `<meta name="robots" content="noindex">`。
- 色と書体は `:root` の変数。テーマの増やし方は `light.html` の `data-theme` に合わせるが、業種ページは変数を直書きして1店1ファイルにする。
- 置き換え箇所は本文に「架空」「例」「【】」のどれかで残す。住所の番地は `XX` のままにし、実在の番地を捏造しない。
- 電話は `tel:`。外部リンクは `target="_blank"` と `rel="noopener noreferrer"`、新規タブである旨をスクリーンリーダー向けに添える。
- 装飾 SVG は `aria-hidden="true"`。意味のある表は `th scope="row"`。
- 地図は埋め込み iframe を置かない。リンクだけ（スナリと同じ。重い外部フレームを最初の画面に載せない）。
- デバッグ用のコンソールコピーボタンは、麺屋たろうとスナリの社内確認用。**納品 HTML には置かない。** この下書きにも置いていない。
- アニメーションは `opacity` と `transform` だけ。初期状態で文字を消さない。`html.js` が付いたときだけ隠し、IntersectionObserver で `.in` を足す。JS が無いときは最初から読める。
- `prefers-reduced-motion: reduce` では移動も自動スクロールも止める。

## 4. レスポンシブ

確認幅は **1280px（PC）** と **375px（スマホ）**。横スクロールが出ないこと。

- 見出しは `clamp`。余白は `clamp(16px, 5vw, 40px)` 前後。
- 720px 以下で、ヘッダーの横リンクを `<details>` のメニューに畳む。電話はメニュー内と固定バーの両方から辿れる。リンクを `display: none` しただけで終わらせない（既存2サンプルの不足）。
- 560px 以下で、品書きの説明は価格の下へ折り返す。点線は隠す。
- 2カラム（考え方、店舗案内、ヒーローの札）は 760px 以下で1カラム。
- 固定バーのタップ領域は高さ 48px 以上。ボタンの文字は 13px 以上。
- ホバーでだけ伝わる情報を置かない。

## 5. アクセシビリティ

- 本文と地のコントラストは、通常文字でおおよそ 4.5:1 以上。弱い文字色を薄茶のまま放置しない（スナリの `--ink-soft: #7a6a5c` は地の色によっては足りない）。アクセントを小さい文字に使うときも同じ。
- 白文字を載せるボタン地は、十分暗い色にする。
- 最初のタブで「本文へスキップ」が出る。`:focus-visible` の輪郭を消さない。
- メニューは summary のままキーボードで開閉でき、Escape と外側クリックで閉じ、項目を選んだら閉じる。
- 画像を将来入れるときは、情報には alt、装飾は `alt=""`。幅と高さを指定する。
- 自動で再生する音、点滅、3秒以上ループする動きを置かない。マーキーを使うなら `aria-hidden` とし、reduced-motion で止める（ライトの標準ではマーキーなし）。
- 言語は日本語。店名の英字は補助であり、英字だけにしない。

## 6. 表示速度

- リクエストは HTML と Google Fonts のみ。画像も解析タグも地図 iframe も置かない。
- `preconnect` を fonts.googleapis.com と fonts.gstatic.com に張り、`display=swap`。
- ローディング画面で本文を覆わない。麺屋たろうのローダーは世界観としては成立しているが、ライトの合格ラインは「開いた瞬間に店名が読める」こと（スナリ側）。
- スクロール監視のパララックスと、数字のカウントアップは標準にしない。見るたびにレイアウトを動かさない。
- ギャラリーで実物を iframe 縮小表示してよい。枚数が増えたら、フォントの重複取得を避けるため静止サムネイルへ替える。

目安: ローカルで開いて店名がすぐ読める。ネットワークはフォント以外に増えない。

## 7. 文章と事実

既存カタログ `templates/index.html` の運用ルールを、テンプレにも適用する。

- 住所・電話・営業時間は、納品時に Google マップの表示を見て転記する。下書きの `XX` と `03-0000-` を残したまま渡さない。
- 価格は税込か税別かを書く。下書きの価格は「例」。
- 創業年・許可番号・有資格は、確認できたものだけ。無い行は削除する。
- 口コミ、受賞、「地域No.1」、治療効果の保証は書かない。
- 整体は医療行為ではないこと、強い痛みやしびれは医療機関へ、をページ内に残す。
- 建設は受けない工事（大規模、許可外）を短く書いて範囲を誤認させない。

## 8. ギャラリー

社内一覧は `templates/gallery.html`。検索には出さない。

1. 何のページか（業種の下書きであり、実在店ではない）
2. 品質基準の要点（この文書の短縮）
3. 状態の語彙  
   - **構想** … 設計だけ。HTML はない  
   - **作成済み** … HTML がある。ブラウザ確認前  
   - **動作確認済み** … PC 幅とスマホ幅で表示と主操作を確認した
4. 業種カード（縮小プレビュー、配色、架空の店名、状態、プレビューへ）
5. 基準サンプルへのリンク（麺屋たろう、スナリ）。中身は改変しない
6. まだ構想のもの（複数ページ、写真枠、予約、日英）

## 9. 納品前チェック

- [ ] 店名・住所・電話・営業時間が実在の表示と一致する
- [ ] 架空・例・`XX`・`03-0000-` が残っていない
- [ ] 写真を入れるなら業種別の写真方針に沿い、容量と alt がある
- [ ] 1280px と 375px で横スクロールがない
- [ ] スマホのメニューから全セクションと電話へ行ける
- [ ] キーボードだけでスキップ、メニュー、主要リンクを操作できる
- [ ] 固定バーが最終行を隠していない
- [ ] noindex を外すのは公開店ページだけ。カタログは外さない
- [ ] コンソールにエラーがない

## 10. 既存サンプルとの差分（意図）

新しい下書きは、2サンプルの見た目をコピーしていない。足りなかった点だけを基準側で埋めている。

| 観測したこと | 基準での扱い |
|---|---|
| 720px 以下でナビ文字リンクが消える | メニューとして残す |
| `.rv` が JS 無しだと透明なまま | JS が付いたときだけ隠す |
| reduced-motion 未対応 | 対応を必須にする |
| フォーカスの見た目が未指定 | `:focus-visible` を残す |
| 弱めの文字色 | 地に対して読める濃さにする |
| 絵文字の地図ピン | 装飾 SVG ＋テキスト |
| デバッグボタン | 納品物・この下書きには置かない |
| ローダー、粒子、パララックス、カウントアップ | ライトの標準から外す |
