開発元hihahoの製品開発ロードマップ（**2026年9月8日時点・Confidential**）。大型機能のみ記載で、小さな改善・バグ修正は含まれない。

> ⚠️ **取り扱い注意**: 原本は Confidential 指定。資料そのものの転送・公開は不可。商談では「開発元のロードマップ上の予定」として口頭紹介に留め、時期・内容は変更されうる旨を必ず添えること。

## Q2 2026（済み・リリースノート反映済みの項目を含む）

### AI
- **AIコーチングモード**: 誤答時にAIが誘導質問（ソクラテス式・最大2ラウンド）で正答へ導く
- **音声インタラクションのAIボイスオーバー**: テキスト入力＋声選択で音声自動生成。視聴者ごとのパーソナライズ、フォルダ単位の声設定、自前APIキー（BYOK）保管に対応
- **AI機能の開発高速化**: AI基盤を単一内部フレームワークへ再構築
- **自由記述の部分点**: AI採点で「部分正解」判定＋対応フィードバック。AIの講評はAPI・統計CSVから取得でき、得点/満点もAPIで返す

### ラーニング＆開発
- **動画アンケートのPDFレポート**: 企業・機関ブランドのPDFサマリーをダウンロード/メールで提供（コンプライアンス用途）
- **視聴者ポータル**: 視聴者を個別登録し個人視聴リンクを発行（アカウント・アクセスルールは後続）
- **複製・翻訳動画でのアダプティブテスト維持**: スコア・分岐設定がコピー後も保持

### 制作体験
- **質問タイマー**: 制限時間つき質問
- **翻訳コピーの改善**: 字幕も翻訳、引き継ぐ要素を選択制に
- **共有ソースの一括差し替え**: 最大25本を一括バックグラウンド処理

### プラットフォーム
- **Kinescopeライブ配信対応**（既存Kinescope連携の拡張）
- **任意URLの動画再生**: HLS(.m3u8)/MP4リンクをソースにできる（自社ホスト動画含む）
- **Panoptoアップロード**: hihahoからPanoptoへ直接アップロード。字幕インポート・AI文字起こしも対応
- 基盤系: PHP 8.5移行、型チェック7倍高速化、大規模アカウントでの統計/再生トラッキング高速化、セキュリティ強化（クロスアカウントアクセス・ログイン再利用・アップロード偽装・類似ドメイン対策）、型安全なフロントエンド＋自動テスト、AI支援開発の安全網

## Q3 2026（進行中）

### AI
- **エディタ内AIアシスタント**: 動画・設定・成績について自然言語で質問し、チャットからAIアクション（文字起こし・チャプター生成・問題生成）を実行（各実行前に確認ステップ）
- **AI問題生成（選択式）**: 正解1＋誤答＋選択肢別フィードバック付き
- **スクリプトから動画構築**: 台本を貼るとAIが質問と分岐ナビを作成
- **AIサマリー＆用語集パネル**: 動画に追従するAI要約と重要用語集のサイドパネル
- **AI音声吹き替え**: 音声を他言語にAI翻訳し追加音声トラックとして付与（1動画で多言語対応）
- **公開前チェック**: SCORM結果をブロックする冒頭ポーズ画面等のよくある問題を検出、ワンクリック修正
- **AI回答評価の再設計**: 参照ソース・厳しさ・フィードバックのトーンを独立制御（Assessmentタブ・フォルダ既定値・Word/PowerPointの文脈資料対応）
- **動画の学習目的設定**: 総括的/形成的等を指定するとAIが問題とフィードバックを目的に合わせる
- **フォルダ用語リスト**: ブランド名・専門用語の表記を自動字幕に反映
- **質問の読み上げ**: 質問と選択肢をAI音声で読み上げ
- **AI処理の欧州域内限定設定**: フォルダ単位でテキスト生成・自動字幕・AI音声を欧州プロバイダに固定

### ラーニング＆開発
- **リテンションカーブ・字幕利用統計**の新チャート
- **定期統計レポート**: 日次/週次/月次で自動メール送信
- **多言語音声切替**（JW Player・Vimeoのみ）
- **cmi5/xAPIパッケージエクスポート**（完了・スコア・レジューム連携）
- **質問セット**: 質問をひとまとまりに（タイムラインから直接編集・AI命名・一括グループ化）※再利用可能な問題バンクはQ4
- **動画内検索**: 字幕・チャプター・インタラクションを検索して該当時点へジャンプ
- **アクセシビリティ（WCAG 2.2 AA）**: キーボード＋スクリーンリーダー対応を段階的に完成
- **学習システムへの詳細データ送信**: 実視聴時間・視聴セグメント・全画面・字幕使用。xAPIバージョン指定・カスタム認証ヘッダー対応
- **選択式への追記回答欄**: 選択肢に自由記述フォローアップを付加（結果PDFに反映）
- **統計ページ刷新**: 視聴者1人の行動を辿るセッション詳細ページ

### 制作体験
- **ビジュアルシナリオフローエディタ**: 動画間の成功/失敗遷移をキャンバス上でドラッグ編集
- **クリック再生サウンド** / **音声付き自動再生**（不可時はミュート自動再生へフォールバック）
- **ポーズ画面に画像＋続行ボタンを直接配置**
- **クリックで開くポップアップ**（テキスト/画像/フレームをボタンの背後に隠す）
- **タイムライン再構築**（Q4機能の土台）・**エディタの実プレイヤー描画プレビュー**
- **スポイトカラーピッカー**・**ホバーツールチップ**・**任意動画のソース差し替え**

### プラットフォーム
- **フォルダごとのアップロード先プラットフォーム選択**
- **Vimeo動画のAI文字起こし**（Standardプラン以上）
- **LTI 1.3連携**: LMSから直接起動、ディープリンク、成績自動返却
- **パートナー管理ダッシュボード**
- **全動画ページの機械可読版**（プレーンテキスト＋構造化データ → AIアシスタント・検索エンジン・パートナーシステム向け）
- **パートナー向け公開インテグレーションガイド**（OpenID Connectでの自社プラットフォーム内Studio起動等）
- **API経由のプレイヤー・埋め込み設定変更**

## Q4 2026（予定）

### AI
- インタラクション過密のAI警告 / 質問タイプのAI提案 / **ワンクリックAIオーサリング**（文字起こし→チャプター→問題→インタラクション提案まで一括）
- **AIによるアダプティブテスト自動構築** / **視聴後AIデブリーフコーチ**（スコア画面でAIと対話）
- 字幕翻訳の精度向上（チャンク分割＋キュー単位リトライ）
- **評価ルーブリックの強化**（性能レベル記述・品質チェック・承認ステータス付きバージョン管理・セッション統計にルーブリック別スコア）
- **AI安全性**: 学習者回答によるAI採点誘導の防止、機微データのAI送信除外、隠れ指示の警告

### ラーニング＆開発
- **必須インタラクションのスキップ防止**（前方シークのみ制限・動画単位設定）
- **複数LRSへの同時送信**（xAPI・Caliper）
- **予約公開** / **プレイヤー内の関連動画切替**（言語・難易度違い等）
- **ライブ配信中の質問インタラクション**（リアルタイム出題）
- **再利用可能な問題バンク**（フォルダ単位・AIで難易度違いを生成）
- **質問セット進捗トラッカー** / **アダプティブ評価の統合モデル**（スコア分岐・チェックポイント・複数セット比較）
- **ラーニングパス**: 複数動画をコース化し進捗を通貫管理

### 制作体験
- **ポーズ画面の自動再開** / **複数作成者のコラボ＋承認ワークフロー**（コメント・@メンション・公開承認）
- **外部レビュアー招待** / **動画ロック・インタラクショングループロック**
- **ホバー/クリック時のスタイル設定** / **1動画内の多言語インタラクション**（言語切替で1本化）
- **フォルダ単位のインタラクションブランディング** / **再利用可能クリップ**（差し替えると全利用動画に反映）
- **動画ノート**（時点指定の社内メモ） / **Studio内画像編集**（切り抜き・回転・注釈）
- **共有リンク/埋め込みごとの個別設定**
- **タイムラインのズーム・トリム表示・字幕編集・アンドゥ**

### プラットフォーム
- **パスキーサインイン**（Face ID / Touch ID / Windows Hello / セキュリティキー）
- **大規模視聴分析の新基盤（MVP）** / **埋め込み用開発者SDK**（JavaScript・React/Vueコンポーネント・視聴イベント連動）
- **セルフサービスのプレイヤーブランディング** / **ページ再読込なしの動画切替**
- **パートナープラットフォーム内のhihaho Studio**（サイレントSSO・自動アカウント作成。第1弾はPanopto次世代基盤）
- **メディアアップロードのAWS S3移行** / **スマホで撮影→即公開**（字幕・AIインタラクション自動付与）
- 基盤系: Laravel 13 / Tailwind CSS 4 / Livewire 4 / Filament 5 への移行

## Q1 2027（予定）

### ラーニング＆開発
- **エンゲージメントヒートマップ**: タイムライン上でシーク・リプレイ・離脱・クリックを色分け表示
- **関連動画サイドバー**（非埋め込みページ）
- **検証可能な学習資格情報**: 合格時に CLR / Open Badges 3.0 を発行（hihaho外でも通用する証明）
- **国別アクセス制限**（地域ライセンス・コンプライアンス対応）

### プラットフォーム
- **Jet-Stream連携**（動画ソースとして接続）
- **ダウンタイム中の再生継続**（プラットフォーム一時停止時も視聴者の再生は維持）

## 営業上の使いどころ

- **教育・研修案件**: Q3のLTI 1.3・cmi5/xAPI・WCAG 2.2 AA、Q4のラーニングパス・問題バンク、Q1'27のOpen Badges は、LMS連携・アクセシビリティ・コース化要件のある案件の先回り材料
- **セキュリティ重視の顧客**: Q3「AI処理の欧州域内限定」は、AI利用時のデータ所在を問う顧客への回答強化材料（[[顧客FAQ：データ取扱・視聴トラッキング・大規模配信（15問）]]と併用）
- **大規模配信案件**: Q4の新分析基盤・複数LRS送信・SDKは、1万件超配信・システム連携要件の商談で「今後の拡張性」として提示可能
- **時期は保証しない**こと。あくまで開発元の計画であり四半期はスライドしうる
