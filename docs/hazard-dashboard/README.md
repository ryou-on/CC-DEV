# MIZUMIRU — ハザードダッシュボード

**Phase 1 / v0.2.0 α / 2026-09-09**

全国の公的ハザード情報の閲覧と、選択地点の地形を使った学習用3D参考モデルを、一つの画面にまとめたWebアプリです。国・自治体の公式アプリではありません。

> **重要：3Dの出力は実際の浸水予測ではありません。**
> 河川氾濫・下水道・堤防・潮位・水の流れを解く水理解析は未実装です。避難判断、建物の安全性判断、保険・不動産の判断には利用しないでください。公的な警報・避難情報・自治体の原図を優先してください。

## 起動する

`public/hazard-dashboard/index.html` がアプリ本体です。自治体表示用の `municipal.js` と `data/` も同じディレクトリに配置してください。npmビルド、APIキー、CDNのJavaScriptは不要です。地図・検索・標高・建物の取得にはインターネット接続が必要です。

CC-DEVリポジトリのルートで、Pythonがある場合：

```sh
python -m http.server 8080 --directory public
```

ブラウザで `http://localhost:8080/hazard-dashboard/` を開きます。ファイルを直接開くよりHTTP/HTTPSでの利用を推奨します。現在地・クリップボードの機能はブラウザの許可やセキュアコンテキストの制約を受けます。iPadで利用する場合は、まずHTTPSで公開してください。

## 操作

住所・地名を検索して候補を選ぶか、緯度・経度を入力します。地図上のクリックでも選択できます。左側からハザードを1種類ずつ切り替え、3Dタブで周辺の地形と仮の水位を比較します。

| 機能 | 実装範囲 |
| --- | --- |
| ハザード | 洪水（想定最大規模）、内水、高潮、津波、土砂災害の切り替え。土砂災害は3種類の区域をまとめて表示 |
| 背景地図 | 地理院の淡色地図、標準地図、航空写真 |
| 地点選択 | 地名検索、緯度経度、地図クリック、許可制の現在地取得 |
| 主要地点 | 亀戸、東京駅、新小岩、梅田、名古屋駅、博多駅、札幌駅、金沢駅 |
| 保存 | 最大30地点をこのブラウザに保存。クラウド同期は未実装 |
| 3D | 選択地点の周囲400m・800m・1,600m四方。標高が取得できる場所が対象 |
| 雨量モード | 雨量、継続時間、流出率、排水能力を変更。時間割合の再生・停止 |
| 水位モード | 選択地点の地盤からの相対水位を−5m〜+10mで変更 |
| 表示 | 回転、拡大縮小、鉛直方向の表示倍率、視点リセット |
| 建物輪郭 | 任意操作でOSMから取得。高さは一律9mの模式値 |
| 共有 | 地点・条件を含むURLフラグメントをコピー。共有にはWeb公開が必要 |
| 書き出し | 計算条件、結果、出典、取得日時、制約をJSONに保存 |
| デバッグ | 「コンソールをコピー」。座標・検索語・保存地点を除いたログ |

タイル取得に失敗した場合はエラーまたは未取得として扱います。未着色の地点を「安全」と判定しません。3Dの標高に欠損があれば、0mや架空の標高で補完せず計算を停止します。ハザードの整備・配信範囲は全国一律ではありません。

## 3D参考モデルの計算

国土地理院の標高タイル `dem_png` のズーム14を読み、対象範囲を64×64セルに区切ります。四隅の標高の平均を各セルの代表標高にします。DEM10B相当のデータです。PNG内の0.01mという格納単位は、地形の測定精度を意味しません。

### 雨量モード

```text
有効貯留高 mm = max(0, 雨量 mm/h × 流出率 − 排水能力 mm/h)
                 × 降雨時間 h × 進行割合
貯留量 m³ = 有効貯留高 mm / 1000 × 対象面積 m²

各セルの水深 = max(0, 一様水位 − セルの代表標高)
```

全セルの貯留量の合計が雨量から得た体積に一致する水位を、二分探索で求めます。

この計算は、初期貯留ゼロ、区域外との流出入なし、雨量・流出率・排水能力は区域内で一様、すべての低地は水理的につながっている、という強い仮定を置きます。独立した窪地への水の到達は判定しません。流速・到達時刻も計算しません。範囲の広さを変えると、仮定する閉鎖区域自体が変わります。

### 水位モード

選択地点の標高に、手動の相対水位を加えて一様水位を指定します。雨量との対応は計算しません。選択地点の水深が0mでも、それより低い周囲の地形に水面が出る場合があります。

### 描画と建物

同じ標高から三角形の地形メッシュを生成します。水面は三角形を水位で切り取って描きます。セル代表標高での体積計算と三角形での描画の間には、離散化の差があります。鉛直倍率は見え方だけを変え、計算値は変えません。

通常はWebGLで描画します。利用できない端末では、同じメッシュをCanvasに透視投影する簡易3D表示に切り替えます。簡易表示では地図画像の細部、透明面の重なり方、処理速度に制限があります。

OSM建物は単純な閉じたwayを最大650棟まで表示します。全建物の高さ9mは模式値であり、実際の階数・高さ・屋根を示しません。地下空間はありません。建物は流れを遮る障害物として計算しません。PLATEAUの実建物モデルは未実装です。

## データの出典

アプリ内の「出典」と地図下部にも表示しています。外部データの権利・条件はそれぞれの提供者に従います。公開前に利用地域に関する条件も確認してください。

- ハザード：国土交通省各地方整備局等・都道府県・市町村等／ハザードマップポータルサイト。
  https://disaportal.gsi.go.jp/hazardmapportal/hazardmap/copyright/opendata.html
- 土砂災害：国土数値情報を国土地理院が加工した配信データ。上記配信ページの地域別条件・出典も参照。
- 地形・背景地図：国土地理院の地理院タイルを加工。
  https://maps.gsi.go.jp/development/ichiran.html
  https://maps.gsi.go.jp/development/demtile.html
- 建物輪郭：© OpenStreetMap contributors / ODbL。Overpass APIで取得。
  https://www.openstreetmap.org/copyright
  https://overpass-api.de/
- 地名検索：地理院地図の検索サービス。
  https://msearch.gsi.go.jp/address-search/AddressSearch
- データ更新・掲載停止情報：
  https://disaportal.gsi.go.jp/hazardmapportal/hazardmap/update/update.html

凡例は配信元の画像を参照します。地点カードはタイル画素の着色有無だけを照会し、画素色から正確な浸水深や危険度を推定する処理は行いません。複数河川の想定等についても公式原図で確認してください。

外部サービスのURL・CORS・稼働状況・配信範囲は変わる可能性があります。APIの永久提供を保証するものではありません。

## 保存・通信・プライバシー

お気に入りはlocalStorageです。自前サーバーへの保存、Firebase認証、アクセス解析はありません。地図・標高のタイル座標、地名検索の入力、建物検索の範囲などは各外部提供先に送られます。現在地取得は利用者がボタンを押して許可した場合に限ります。

共有URLと結果JSONには地点の座標が含まれます。自宅などのURLを他者へ渡す際は注意してください。デバッグコピーからは座標・検索語・地点名を除きます。

## CC-DEVに配置する

本アプリは既存のFirebase Hosting公開フロー（mainへのpush）で配信します。

既存のFirebase設定は変更せず、次のファイルをCC-DEVへ追加する構成です。

```text
CC-DEV/
└── public/
    └── hazard-dashboard/
        ├── index.html
        ├── municipal.js
        └── data/
```

既存のGitHub Actionsはmainへのpushを契機に、Firebase Hostingのmainターゲットへ公開します。

GitHub Actions： https://github.com/ryou-on/CC-DEV/actions

本番URL（公開後）： https://cc-dev-ps7.web.app/hazard-dashboard/

静的ファイルとして配信するため、アプリ自身のビルドやFirebase Functionsの追加は不要です。Firebase Hostingで使うAPIキーもアプリ内には必要ありません。
