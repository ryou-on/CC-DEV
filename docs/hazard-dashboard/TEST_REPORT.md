# MIZUMIRU v0.1.1 公開前検証

実施日：2026-09-09。Mac上のChrome / Playwrightを使用。

## 合格した項目

- `node tests/hazard-dashboard-core.cjs`：埋め込みJavaScript構文、標高デコード、座標変換、欠損標高での停止、平坦地の水深、排水、負の相対水位、500条件の体積収支。
- 実通信：亀戸周辺の背景地図、洪水タイル、凡例、標高（−0.8m）、亀戸の住所検索。
- WebGLの3D地形生成と計算、相対水位2mの反映、条件・結果のJSON出力。
- Overpass APIから建物輪郭650棟を取得。
- 地図最大化、再読み込み後の最大化維持、Esc復帰。
- 地点のお気に入り保存と再読み込み後の保持。
- 1440×1000と768×1024の画面を目視確認。
- 検証中のJavaScript実行時エラー0件、通信失敗0件。
