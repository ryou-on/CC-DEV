# 未ログイン利用者への影響

この変更を本番の Firestore ルールと一緒に公開したときの影響です。本番ルールはまだ公開していません。比較対象は、認証なしで読み書きできる現行の本番ルールです。

「移行」は、管理者が `scripts/manage-share-grants.cjs` で Google アカウントを reader または writer に入れることです。初期状態ではプラットフォーム管理者以外は共有データを触れません。

| アプリ | 今の未ログイン利用 | 公開後 | 利用者への案内 |
|---|---|---|---|
| app-dashboard | アプリ一覧の閲覧・追加・評価・削除ができる | Google ログインと `apps__registry` の許可が必要。未ログインは一覧も出ない | 編集する人にログインと writer 許可を案内する |
| note-analytics | ユーザーIDを知っていれば週次スナップショットの保存・一覧・削除ができる | `note-analytics__{userId}` の許可が必要。Chrome の自動送信もログイン中のセッションがないと失敗する | 自分の userId に対する writer 許可を案内する。使い方の初期設定にもログインを追記済み |
| ouchi-hamasushi | 家族コードだけで音声・画像が端末間同期される | `ouchi-hamasushi__{家族コード}` の許可が必要。端末内の localStorage に既にある音声は残る。新しい同期と削除はログイン後だけ | 家族の各端末で Google ログインし、家族コード単位で writer を渡す |
| tomoe-home | アプリリストを認証なしで共有できる | `tomoe-home__{設定ID}` の許可が必要。取得済みの localStorage は残る | 共有している家庭にログインと許可を案内する |
| tomoe-player | 動画リストと視聴ログを認証なしで読み書き・削除できる | `tomoe-player__{リストID}` の許可が必要 | リストを共有している人にログインと許可を案内する |
| bombing-bay | 認証なしでランキングへプレイ結果を送れる | `bombing-bay__global` の writer 許可がないと送信できない。更新と削除は許可ユーザーでも不可 | ランキングを残す人にログインと writer 許可を案内する。未ログインの対戦そのものはローカル処理 |
| meet-knowledge | チームコードだけで Q&A を読み書き・削除できる | `meet-knowledge__{チームコード}` の許可が必要 | チームメンバーにログインと許可を案内する |
| outreach-crm | ワークスペースコードだけでリード配列を共有できる | `outreach-crm__{ワークスペース}` の許可が必要。画面内のローカル保存は残る | 利用端末ごとにログインと許可を案内する |
| hihaho-view の再生回数 | 匿名の +1 書き込みがあった | クライアントは書き込み関数を空にしてあり、ルールも未ログインの +1 を拒否する。動画の再生（playlists の公開読み取り）は続く | 視聴者への案内は不要。編集者には再生回数の自動加算が止まることを伝える |
| hihaho-admin の再生回数一覧 | 編集者が全件取得している | 編集者（hihaho 編集者条件）は読める。未ログインは読めない | 編集者のログインは従来どおり。追加の grant は必須ではない |
| hihaho-view / hihaho-player / 公開KB / 素材カタログ | 公開ドキュメントの読み取り | 変更なし。playlists、video_meta、audience=public の KB、素材カタログは公開読み取りのまま | 案内不要 |
| hondoko の共有リンク | link / public モードは未ログインで蔵書を閲覧できる | 変更なし。sharing ドキュメントの公開読み取りも残る（viewers のメールアドレスが見える残リスク） | 案内不要。メール一覧を隠すなら sharing の公開読み取りをやめる別変更が必要 |
| coco-itta | もともと Google ログイン。ただし匿名サインインでもグループ文書と写真を読み書きできた | 確認済みアカウントだけがグループを get できる。全件の list は拒否。ID を知っていれば参加できる。ピンの更新と削除は members の人だけ。写真は確認済みアカウントならパスを知っていれば読める | 普段の Google ログイン利用者への案内は不要。匿名サインインは使えなくなる |
| Flight Strip TODO（安定版・開発版） | タスクは自分の uid。利用統計・フィードバック・カウンタはログインしていれば誰でも読み書きできた（匿名サインインを含む） | タスクは確認済みアカウントかつ自分の uid。セッション記録は確認済みアカウントならできる。目安箱の作成・状態変更・カウンタはクライアントから拒否し、Cloud Functions（App Check、確認済みアカウント、1分5件・1日50件）だけが `unreviewed` で保存する。受信箱の閲覧と状態変更は確認済みの hihaho 編集者だけ。匿名サインインは拒否 | 普段の Google ログイン利用者はタスクを続けられる。フィードバックは確認済みアカウントと App Check が必要。統計画面は確認済みの編集者メールだけ。手順は `docs/fst-feedback-api.md` |
| meishi-db | 自分の `users/{uid}` だけ | 変更なし | 案内不要 |
| mini-me / 会議通訳 / 本ドコの有料API | 呼び出し元によっては未ログインでも関数に到達し得た | 確認済み Google アカウント、App Check、costControls の許可 UID がないと関数が拒否する | 使う人の UID を costControls に入れる。App Check の強制適用はコンソール作業が残っている |

公開読み取りのまま残るもの（プレイリスト、サムネイルメタ、素材、公開KB、Storage の画像、hondoko の sharing）は未ログインの閲覧を壊しません。書き込みと削除は編集者か許可ユーザーに限られます。
