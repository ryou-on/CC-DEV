# X Fullscreen Reader

Xのタイムラインを「1記事1画面・大きな文字」で読むChrome拡張（老眼対策）。

## インストール
1. `chrome://extensions` → デベロッパーモード ON
2. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択
3. x.com を開いて再読み込み

## 操作
| キー | 動作 |
|---|---|
| Alt+R / 右下📖 | リーダー起動・終了 |
| → / ← | 次の記事 / 前の記事 |
| fn+→ / fn+←（End / Home、または Shift+→ / Shift+←） | リプライへ入って送り / 戻り（最初のリプライより前で fn+← するとタイムラインへ復帰） |
| fn+↑ / fn+↓（PageUp / PageDown、または Shift+↑ / Shift+↓） | ブックマーク先ピッカーを開く |
| ↑ / ↓ | 長文をスクロール |
| ピッカー内 ↑↓ / J K | 選択移動 |
| X | 選択（複数可） |
| Enter | 決定（未選択ならカーソル位置） |
| R | フォルダ再取得 |
| + / - | 文字サイズ |
| T | 白黒切替 |
| Esc | 閉じる |

## 注意
- ブックマークフォルダはXの画面操作（共有→フォルダに追加）を代行して取得・追加します。Xの仕様変更で動かなくなる場合があります。
- 取得したフォルダ名は chrome.storage にキャッシュされます。
